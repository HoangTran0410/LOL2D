# Cheat Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The practice panel drops to three tabs — Đấu thủ, Trận đấu, Gian lận — gains per-unit cheats, and Escape stops ending the match.

**Architecture:** Cheats go through `MatchDirector` like every other live-match mutation; the mechanisms live where this codebase already puts them (a `Buff` for invulnerability, a method on `Spell` for stacks). The Chiêu thức tab is deleted because `RosterTab`'s loadout editor is a superset of it.

**Tech Stack:** TypeScript, p5.js global mode, Vue 3 (`<script setup>`), Vitest (`environment: 'node'`), Playwright.

**Spec:** `docs/superpowers/specs/2026-08-15-cheat-tab-design.md`

## Global Constraints

- **p5 global mode.** Nothing may touch `createVector`/`deltaTime`/`textSize` at module eval time.
- **Every control needs a touch handler beside its click handler.** `GameScene` `preventDefault()`s every touch page-wide, which suppresses the synthetic click *and* native scrolling everywhere, not just over the canvas. During the practice-panel work this silently killed a checkbox `change`, a range drag and a plain `@click` on three separate occasions. Copy the shape already in `RulesTab.vue` / `WorldTab.vue`.
- **No text inputs.** p5 binds `keydown` on `window`; typing casts abilities and Escape leaves the scene.
- **`RosterTab`'s invariant, wherever the director is called from a component:** every director call is followed by `version.value++`. The director is `markRaw`'d on purpose and is not reactive.
- **Commit form:** `git add <new files>` then `git commit -m "..." -- <explicit paths>`. Never `-A`, never `.`, never bare. Trailer: `Claude-Session: https://claude.ai/code/session_017chrooEFCy9rvuYkvD9mjh`
- **Prettier**: match `.prettierrc` (2 spaces, single quotes, trailing commas, 100 cols) in new files; never `--write` existing ones.
- **Tests are written first and their failure read.** A failure resolving to `undefined` means a missing export — proceed. A failure showing a *conflicting real value* means this plan is wrong — stop and report.

`src/game/gameObject/buffs/Invulnerable.ts`:

```ts
import AssetManager from '../../../managers/AssetManager';
import BuffAddType from '../../enums/BuffAddType';
import Buff from '../Buff';

/**
 * Takes no damage from anything, and nothing else.
 *
 * Deliberately not `StatusFlags.Invulnerable`: that flag is in the enum but
 * nothing reads it — `ActionState` has no matching bit and
 * `Stats.updateActionState` has no line for it. What works is
 * `modifyIncomingDamage`, which `AttackableUnit.takeDamage` already loops
 * every buff through, returning early once damage reaches zero. `Stasis` is
 * built on exactly this.
 *
 * Deliberately not `Stasis` itself, which is this *plus* a stun and a dropped
 * `Targetable`: a player who switches invulnerability on to practise a combo
 * must still be able to move and cast.
 *
 * Icon reuses the Zhonya's hourglass — it reads correctly and needs no new
 * asset.
 */
export default class Invulnerable extends Buff {
  image: Buff['image'] = AssetManager.get('buff_stasis');
  name = 'Bất Tử';
  buffAddType = BuffAddType.REPLACE_EXISTING;

  modifyIncomingDamage(): number {
    return 0;
  }
}
```

On `MatchDirector` — `INVULNERABLE_DURATION_MS = 600000`, matching the other never-expiring buffs (`Veigar_Q_Power`, `ChoGath_R_Growth`); the toggle turns it off with `deactivateBuff()`, so the duration is a backstop, not the mechanism:

```ts
  isInvulnerable(unit: Champion): boolean {
    return unit.buffs.some(buff => buff instanceof Invulnerable);
  }

  setInvulnerable(unit: Champion, on: boolean): void {
    const existing = unit.buffs.filter(buff => buff instanceof Invulnerable);
    if (on) {
      if (existing.length === 0) unit.addBuff(new Invulnerable(INVULNERABLE_DURATION_MS, unit, unit));
      return;
    }
    for (const buff of existing) buff.deactivateBuff();
  }

  /** The same two lines `applyLoadout` runs after a champion swap. */
  refill(unit: Champion): void {
    unit.stats.health.baseValue = unit.stats.maxHealth.value;
    unit.stats.mana.baseValue = unit.stats.maxMana.value;
  }

  /**
   * `BasicAttack` overrides `currentCooldown`'s setter with an empty one on
   * purpose, so the swing timer this does not reach is the swing timer it
   * should not reach.
   */
  clearCooldowns(unit: Champion): void {
    for (const spell of unit.spells) if (spell) spell.currentCooldown = 0;
  }
```
